POCKET DIAMOND — web build

Upload this whole folder to any static host (Cloudflare Pages, Netlify, Vercel, GitHub Pages,
or a folder on your own site). Open index.html. On phones, "Add to Home Screen" installs it full-screen,
and it keeps working offline after the first visit.

Note: ONLINE 1v1 uses the claude.ai artifact room, so it works in the claude.ai version only.
On your own host it needs a small realtime server (see the notes from Claude).
